Built

When engineering didn't have the bandwidth, or a process had no owner, I built it myself.
01

Bytecast

Chrome extension · live on the Chrome Web Store

I was retyping near-duplicate bug reports by hand. Bytecast records a web page and captures everything happening on it, then turns that recording into a bug in one click.

  • Built-in lightweight video editing and custom bug templates, or manual entry when there's nothing to record
  • Claude-powered, and can switch models to keep bug write-ups concise every time
  • Files into Jira, ClickUp, and five-plus other trackers out of the box
  • The real trick: every recorded video, console log, network call, and inspected element gets bundled into one interactive file attached to the bug. Open that attachment and it plays back like the live page, logs synced to the exact moment they happened
  • Cross-checks the details a reporter typed against what the logs actually show, so a bug report isn't just a story, it's backed by evidence

View on the Chrome Web Store →

02

Live-Data Order Admin

Internal admin tool

Every test order used to mean a real transaction and a manual API setup, per order, per environment. This tool pulls live data straight from whichever environment you're pointed at, production included, and creates a fully detailed order in one click, no separate setup per order, no extra cost. It was later extended through Greenhouse into a company-wide in-store trial order automation flow.

03

Meijer Self-Serve

In-app feature

Meijer could only place orders through their own system, but every one of those orders still needed QA to manually shop and deliver it inside our app, just to work around internal dependencies. I built a feature giving their own staff direct access to assign themselves as shopper and driver and run the whole flow start to finish, no one on my team involved. Saved ~4 hours of QA time a week.

04

Forgeflow

Android app · internal tool

Records a real session on the phone and turns it into a working test script, cross-platform, no separate build per OS. What used to cost a QA engineer real hours writing and maintaining automation by hand now happens in the time it takes to record the flow once, freeing that time for the testing a script can't do: exploring the parts of the product no one's thought to check yet.
